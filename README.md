# ЧОШ информатор (School Informant Bot)

Telegram-бот для управления школьным расписанием, оповещениями и опросами. Разработан для автоматизации информирования учеников и учителей ЧОШ.

## Внешние переменные (Environment Variables)

Для работы бота необходимо настроить следующие переменные окружения:

| Переменная | Описание |
| :--- | :--- |
| `BOT_TOKEN` | API токен вашего Telegram бота, полученный от [@BotFather](https://t.me/BotFather). |
| `APP_URL` | Базовый URL развернутого приложения (например, `https://your-app.render.com`). Используется для настройки Webhook и механизма self-ping. |
| `ADMIN_Id` | Числовой Telegram ID администратора бота. |
| `GH_OWNER` | Имя пользователя или организации на GitHub для хранения бэкапов базы данных. |
| `GH_REPO` | Название репозитория GitHub для бэкапов. |
| `GH_TOKEN` | Personal Access Token (PAT) от GitHub с правами на запись в репозиторий. |
| `DB_KEY` | Секретный ключ для удаленного скачивания базы данных через эндпоинт `/getdb?key=...`. |
| `PORT` | *(Опционально)* Порт, на котором будет запущен веб-сервер. По умолчанию `8080`. |

## Основные возможности

- **Управление расписанием:**
  - Автоматическая генерация ежедневного расписания на основе базового.
  - Учет отсутствующих учителей и автоматическая корректировка.
  - Возможность ручного редактирования уроков (удаление, замена) через админ-панель.
  - Рассылка обновленного расписания всем зарегистрированным пользователям.

- **Панель администратора:**
  - Управление списком учителей и их предметами.
  - Массовая рассылка объявлений (текст, фото).
  - Создание и управление опросами.
  - Ручное и автоматическое создание бэкапов в GitHub.

- **Профили пользователей:**
  - Регистрация учеников по классам.
  - Личные кабинеты для учителей с их расписанием.
  - Просмотр расписания на сегодня, завтра и неделю.

- **Технические особенности:**
  - Работа через Webhook.
  - Встроенный механизм self-ping для предотвращения "засыпания" на бесплатных хостингах (например, Render).
  - Автоматическое восстановление базы данных из GitHub при запуске.

## Развертывание

Проект написан на .NET 8.0 и использует SQLite в качестве базы данных.

1. Склонируйте репозиторий.
2. Установите необходимые переменные окружения.
3. Соберите и запустите проект:
   ```bash
   dotnet build
   dotnet run
   ```
